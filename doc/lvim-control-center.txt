1. INTRODUCTION                               *lvim-control-center-intro*

lvim-control-center is a floating settings panel. You declare GROUPS (one tab each) of
SETTINGS (toggles, selects, number/string inputs, actions); the panel reads each value,
lets the user change it, persists it to SQLite, and applies it live. The panel is rendered
by lvim-utils, so it shares the lvim-tech UI look and key bindings.

Requires: |lvim-utils| (UI + persistence helpers) and sqlite.lua.

==============================================================================
2. SETUP                                      *lvim-control-center-setup*

Multi-instance: there is NO global singleton. Create an instance with `new(opts)` — it
requires a UNIQUE `command` and owns its own database. `new()` returns the instance
(methods `:open()` `:reset()` `:export()` `:import()` `:close()`); look it up later with
`require("lvim-control-center").get("<command>")`.

`setup(opts)` is a thin loader-facing forwarder over `new()`: pass a SINGLE instance table
or a LIST of them (`{ {command=…}, {command=…} }`). No command / empty table → quiet no-op.

Instance methods: `:open()` `:search()` `:reset()` `:export()` `:import()` `:close()` and the
profiles `:preset_save/load/list/delete(name)`. Registry helpers on the module: `get(command)`,
`list()`, `close_all()`, and whole-profile `export_all(path)` / `import_all(path)`.
>lua
  require("lvim-control-center").new({
      command = "LvimControlCenter",   -- REQUIRED, unique — the command that opens it
      title = "LVIM CONTROL CENTER",   -- header title
      title_icon = "󰒓",               -- Nerd Font glyph before the title
      title_pos = "center",            -- title alignment: "center" | "left" | "right"
      save = "~/.local/share/nvim/lvim-control-center", -- SQLite dir (else derived from command)
      on_change = nil,                 -- fun(name, value, instance): hook after any panel edit
      groups = {                       -- see |lvim-control-center-groups|
          {
              name = "editor",
              label = "Editor",
              icon = "",
              settings = {
                  {
                      name = "wrap",
                      type = "bool",
                      label = "Line wrap",
                      default = false,
                      get = function() return vim.o.wrap end,
                      set = function(v) vim.o.wrap = v end,
                  },
              },
          },
      },
      popup_global = { ... },           -- forwarded to lvim-ui.new()
  })
<
The panel SIZE is NOT set here — it follows the SHARED lvim-ui geometry
(`config.ui.size.float`), so the panel resizes with that shared geometry. `popup_global`
carries the instance defaults (icons, key labels and highlight overrides — see
|lvim-control-center-appearance|).

==============================================================================
3. GROUPS                                     *lvim-control-center-groups*

Each group becomes one tab. *LvimControlCenterGroup*

  name      string     unique group id
  label?    string     tab text (falls back to name)
  icon?     string     tab icon (trailing spaces stripped)
  settings  LvimControlCenterSetting[]   the rows in this tab
  menu?     boolean    force MENU vs FORM layout; omit = auto (menu when the group has
                       only action/spacer rows, form when it has value rows)

==============================================================================
4. SETTINGS                                   *lvim-control-center-settings*

Each setting is one row. *LvimControlCenterSetting*

  name       string   unique id, used as the persistence key
  type       "bool" | "int" | "float" | "string" | "select" | "action" | "spacer"
  label?     string   display name (falls back to name)
  desc?      string   short description; forwarded to the row, used as the label fallback
  default?   any      value applied when nothing is persisted
  get?       fun(ctx): any                   read the current live value
  set?       fun(value, is_load, ctx)        apply a new value; persist via ctx.data:save()
                                              (database, default) or ctx.file(path):save()
                                              (a JSON file — for a project-local override etc.)
  run?       fun(bufnr)                       callback for `action` rows
  options?   any[]    choices for `select` rows
  icon?      string   per-row icon
  break_load? boolean skip applying this setting on startup
  enabled?   fun(): boolean              hide the row when it returns false (evaluated on
                                         open) — for settings that don't apply right now
  disabled?  boolean | fun(value): boolean  render the row dimmed + struck through (value
                                         unchanged); evaluated live so it can track a parent
                                         toggle
  validate?  fun(value): boolean         reject a changed value when it returns false (it is
                                         neither applied nor persisted)

Value resolution on open: `get(ctx)` → the instance's persisted value → `default`. On
change the new value is applied via `set()` (or stored directly when there is no `set`),
and persisted to the owning instance's database.

5. COMMAND                                    *lvim-control-center-command*

The command name is the instance's `command` field — `:LvimControlCenter` below is just
the example name; each instance registers its own.

                                                      *:LvimControlCenter*
:LvimControlCenter                  Open the panel (centred float by default).
:LvimControlCenter float|area|bottom   Open in a layout: `float` (centred, default), `area`
                                    (msgarea/cmdline dock) or `bottom` (bottom float). The
                                    layout token is order-independent with the tab/setting
                                    args, e.g. `:LvimControlCenter bottom appearance`.
:LvimControlCenter {tab}            Open focused on a tab (name or 1-based index).
:LvimControlCenter {tab} {row}      Open focused on a specific setting (name or index).
:LvimControlCenter {setting}        A bare setting name jumps straight to it (its group is
                                    resolved for you).
:LvimControlCenter search           Fuzzy-search every setting across all tabs (via
                                    |vim.ui.select|); the choice opens the panel focused there.
:LvimControlCenter export [path]    Export persisted settings to a JSON file (default:
                                    stdpath("data")/lvim-control-center-<command>-export.json).
:LvimControlCenter import [path]    Import settings from a JSON file and re-apply them.
:LvimControlCenter reset [setting]  Reset one setting (or all when omitted) to its default
                                    and clear the persisted value.
:LvimControlCenter preset save {name}    Snapshot the current settings as a named profile.
:LvimControlCenter preset load {name}    Apply a saved profile.
:LvimControlCenter preset list           List saved profiles.
:LvimControlCenter preset delete {name}  Delete a profile. Profiles live in the instance's DB.

                                                  *:LvimControlCenterList*
:LvimControlCenterList              Pick a live instance to open (cross-instance registry).

Command-line completion offers the verbs, every group, and every setting name — so it
doubles as a quick search across the whole config.

6. NAVIGATION                               *lvim-control-center-navigation*

  j / k          Move between settings
  h / l          Switch group tab
  <CR>           Toggle / cycle / edit / execute the focused setting
  <Tab> / <BS>   Cycle a select option forward / backward
  <Esc> / q      Close

(All configurable via `popup_global.keys`.)

==============================================================================
7. PERSISTENCE                             *lvim-control-center-persistence*

Each instance stores its values in its OWN SQLite database (`lvim-control-center.db`) under
its `save` directory — so instances never share a store. On `new()` the saved values are
re-applied (each setting's `set(value, true, ctx)`), unless the setting sets
`break_load = true`. Requires sqlite.lua.

The database (`ctx.data`) is the DEFAULT. A setting may instead persist to a JSON FILE via
`ctx.file(path)` — the same interface (`:save` / `:load` / `:export_all` / `:import_all` /
`:clear`) backed by a plain file — for the exceptions that belong in a file rather than the
global DB, e.g. a project-local, git-committable override (`.<plugin>.json` in the cwd).

==============================================================================
8. APPEARANCE                               *lvim-control-center-appearance*

The panel is a |lvim-utils| UI instance, themed by the shared `LvimUi*` groups which
self-theme from the lvim-utils palette and follow the active lvim-colorscheme. To override,
pass highlight overrides through `popup_global.highlights`:
>lua
  require("lvim-control-center").new({
      command = "LvimControlCenter",
      popup_global = {
          highlights = {
              LvimUiTitle = { fg = "#89b4fa", bold = true },
              LvimUiTabActive = { bg = "#313244", fg = "#cdd6f4" },
          },
      },
  })
<
See the lvim-utils help (`:help lvim-utils-highlights`) for the full group list.
